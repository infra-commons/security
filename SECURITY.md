# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it privately
rather than opening a public issue — email **security@rolliq.com**.

Where enabled (see this repo's Security tab), you can also use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
— both channels reach the same team.

We aim to acknowledge reports within a few business days. This repository is maintained on a
single rolling `main` branch; there is no supported-versions matrix to consult.
